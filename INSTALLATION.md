# AI Prompt Assistant - Installation Guide

This document provides detailed instructions for installing and setting up the AI Prompt Assistant application on macOS.

## System Requirements

- macOS 10.14 (Mojave) or later
- Internet connection for API features
- OpenAI API key (for prompt optimization)

## Installation Instructions

### Method 1: Using the Zip Archive

1. Download the `AI Prompt Assistant.zip` file
2. Double-click the zip file to extract it
3. Drag the extracted `AI Prompt Assistant.app` to your Applications folder
4. Right-click on the app and select "Open" (required only the first time to bypass Gatekeeper)
5. The app will appear in your menubar

### First-Time Setup

1. Click on the AI Prompt Assistant icon in your menubar
2. Select "Settings" from the menu
3. Configure your preferences:
   - Set your preferred keyboard shortcut
   - Choose your language
   - Enter your OpenAI API key in the AI Selection tab
   - Test your API key using the "Test Key" button
   - Configure startup options

## Troubleshooting

### Application Won't Open

If you see a message that the app "cannot be opened because it is from an unidentified developer":

1. Right-click (or Control-click) the app icon
2. Select "Open" from the context menu
3. Click "Open" in the dialog box that appears

### API Key Issues

If you're experiencing issues with the API key:

1. Verify that your OpenAI API key is correct
2. Check that your API key has sufficient credits/quota
3. Test your key using the "Test Key" button in Settings
4. Check your internet connection

### Other Issues

If you encounter any other issues:

1. Restart the application
2. Check for updates
3. Reinstall the application if necessary

## Uninstallation

To uninstall AI Prompt Assistant:

1. Quit the application by selecting "Quit" from the menubar menu
2. Move the application from your Applications folder to the Trash
3. Empty the Trash
